## 1. 双问题诊断

### 1.1 Bug：卡片入口弹出空查看框（`fix(web)`）

**根因：Vue watch 缺 `immediate`，挂载即真值不触发。** 卡片入口流程：`App.onCardPrompt` 置 `previewIndex` + `promptRequested` → `AssetPreview` 新挂载，其 setup 期 `watch(autoOpenPrompt, …, { immediate: true })` **同步**把 `promptModalOpen` 置 `true` 并渲染 `<PromptModal :open="true">`。而 `PromptModal` 自己的 `watch(() => props.open, …)` **没有 `immediate`**——组件挂载时 `open` 已是 `true`，没有"变化"可监听，回调永不执行，`initPrompt()`（负责 `promptEditing = !props.hasPrompt`）从未运行，`promptEditing` 停在初始值 `false`，于是无提示词资产也停在查看态、文本区空白。

预览面板内「添加提示词」按钮走的是 `open: false→true` 的变化路径，watch 正常触发——这解释了为何只有卡片入口复现。

**修复（`apps/web/src/components/PromptModal.vue`，2 处）：**
1. `open` 的 watch 加 `{ immediate: true }`（附注释说明卡片入口挂载前 open 已为 true）；关闭分支复位逻辑不变。
2. 标题按状态与意图显示：编辑态「编辑提示词 / 添加提示词 · 名称」，查看态「提示词 · 名称」，让弹窗身份与用户点进来的意图一致。

### 1.2 样式：实心蓝徽标突兀（`feat(web)`，design-taste-frontend + apple-design）

**重设计（`apps/web/src/components/AssetCard.vue`）：** 移除原白底/蓝底双态徽标，改为**深色毛玻璃芯片**，与既有时长角标（`bg-black/60`）同材质家族，在浅色 UI 中不再抢焦：

- 统一芯片：`rounded-full bg-black/55 backdrop-blur-sm text-[10px] leading-none` + 四角星提示词图标（`h-3 w-3`），hover 加深至 `bg-black/75`。
- **双态语义**：有提示词 → 常态仅图标（低干扰的持久可达 affordance，悬停展开「查看提示词」）；无提示词 → 悬停卡片才显现「+ 提示词」（创建类操作不常驻）。
- **键盘可达**：无提示词态 `opacity-0` 配 `focus-visible:opacity-100`，Tab 聚焦即现形，不破坏鼠标极简。
- **左下芯片行**：失效徽标与提示词芯片收入同一 `absolute bottom-1.5 left-1.5 flex gap-1.5` 行，二者不再左下角重叠。

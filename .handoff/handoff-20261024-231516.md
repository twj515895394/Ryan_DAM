1. **工作约定**：Python 一律 `.venv\Scripts\python.exe`；每修复一个可验证增量就本地 commit（格式 `fix: ...`），积累后一起 push + 核对 CI；用户确认「修复完成」才算票结。

3. **工程坑位**（都已踩过，别再踩）：

   - FastAPI 0.115 + `from __future__ import annotations` 下 204 路由必须显式 `response_model=None`
   - 导入类测试必须用 `iso_client` 夹具；跑完全量测试确认 `D:\Ryan_DAM\assets` 为 0 条目
   - 文件搬移类操作用 `services/fs_ops.py` 的 `replace_with_retry`（缩略图 worker 会短暂锁文件）
   - 打包验证后清理真实托管根（冻结版默认用 `D:\Ryan_DAM\assets`）
4. **review 遗留的非阻塞建议**（用户若报相关问题可直接定位）：加载更多无防抖（双击重复追加）、搜索 `ilike` 未转义 `%`/`_`、列表 `has_prompt` 拉全量 prompt_text、解除关联后镜像空目录残留、外部扫描仅按 size 判变更。完整清单见 `.handoff/current.md` §0.0。
5. **UI 冒烟方法**（复现前端问题时）：venv 起隔离后端 + `npx vite --port 5173` + localStorage 桥 `ryan-dam-dev-backend` + `window.confirm=()=>true`，造数据走 API（上次会话有 `.ui-smoke/seed.py` 模式可参考，已清理，按需重写）。

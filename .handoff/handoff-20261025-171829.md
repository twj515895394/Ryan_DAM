## 2. 设计决策

- **行高密度**：目录/项目/外部/标签/回收站全部行统一 **24px（h-6）**，Finder 式紧凑密度；行间 `space-y-px`。
- **缩进**：每层 `ml-2 border-l pl-1` = **13px/层**（原 20px/层），深层名称不再被过早截断。
- **截断兜底**：目录名/项目名/标签名 `truncate` + `title` 悬停完整名。
- **可拖拽宽度**：布局根节点 CSS 变量 `--sidebar-w`（默认 256，钳制 [220,480]），`aside` 用 `w-[var(--sidebar-w)]`。
  - 拖拽期间直接 `setProperty` 改 CSS 变量——**每帧零 Vue 重渲染**、指针 1:1 跟手（Apple 流体交互）；`setPointerCapture` try/catch + window 级 pointermove/up 兜底（合成事件无活动指针）；松手才 commit 到 `localStorage['ryan-dam-sidebar-width']`。
  - 键盘等价：`←/→` ±16px、`Home` 复位 256；**双击把手复位**；拖拽期间 body `cursor/userSelect` 锁定。
  - 把手：`role="separator"` + `tabindex=0` + aria-label，8px 命中热区（`-mx-1 w-2` 骑跨分割线），悬停/聚焦/按下时 3px 蓝色高亮条（accent 35/50/60）。

## 5. 冒烟中揪出的真实缺陷（已修）

- `useSidebarResize.ts` 的 `STORAGE_KEY` 字面量曾被写坏为 `ryan-…-width`（U+2026 省略号，首次创建该文件时引入），导致持久化写进错误键、刷新后宽度丢失。冒烟用 localStorage 键码点转储定位，修复为 `ryan-dam-sidebar-width` 并复测通过。**教训：字面量存疑时直接转储键码点，别信肉眼。**
- 既知坑复验：`tab.playwright.evaluate` 匹配外层包装 span 会误报 title 缺失（`title` 在 `truncate` 内层）；`getComputedStyle` 读 CSS 变量用布局根节点。

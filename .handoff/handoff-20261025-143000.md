## 1. 交付明细

### 1.1 后端（级联复用 + 项目统计/级联端点）

- `backend/app/services/folder_service.py`：目录级联六步算法抽为共享函数 `cascade_delete_folder_ids(db, root_ids)`——多根子树去重（`seen` 集合）后依次执行：①解除指向子树的 ExternalSource 关联 → ②子树内 active 托管资产 `trash_asset` 并摘除 folder_id、外部资产 `delete_asset_index`（**源文件永不删除**）→ ③清其余回收站内资产的 `original_folder_id` → ④清 ImportJob/Item 目标目录引用 → ⑤清子树 parent_ids → ⑥逆序删除目录行 → commit。`delete_folder(cascade=True)` 改为薄封装，行为与回归测试完全不变。
- `backend/app/services/project_service.py`：
  - `get_project_stats(db, project_id)`：项目 404 守卫后统计 `subfolder_count / asset_count / managed_asset_count / external_asset_count`。
  - `delete_project(db, project_id, cascade=False)`：以 `parent_id is None` 求项目根目录集合；非空且未指定 cascade 仍抛 409 `project_not_empty`；cascade=True 时调用共享级联算法后再删项目。
- `backend/app/schemas/project.py`：新增 `ProjectStats`（project_id / project_name / subfolder_count / asset_count / managed_asset_count / external_asset_count）。
- `backend/app/api/v1/projects.py`：新增 `GET /api/v1/projects/{id}/stats`（response_model=ProjectStats）；`DELETE /api/v1/projects/{id}` 增加 `cascade: bool = False` 查询参数（204 无响应体），与目录端点 `?cascade=true` 惯例一致。

### 1.2 前端（Apple HIG 项目删除确认流）

- `apps/web/src/composables/useProjectDelete.ts`（新，78 行）：`useProjectDelete(ask)` 返回 `askDeleteProject(projectId, name, afterDeleted)`。流程 = 先 `api.getProjectStats` → 空项目弹轻量 danger 确认（"确定删除空项目「X」吗？"，`deleteProject(id,false)`）；非空弹级联影响说明："包含：N 个文件夹、M 个资产\n\n操作影响：X 个托管资产将移入回收站，Y 个外部素材将移除索引（源文件保留），所有文件夹与子文件夹将被级联删除。"，确认按钮「级联删除」danger intent，`deleteProject(id,true)`；统计接口异常时回退默认级联确认（不阻塞删除入口）。
- `apps/web/src/api/types.ts`：新增 `ProjectStats` 接口；`client.ts`：`deleteProject(id, cascade=false)` 拼 `?cascade=true`、`getProjectStats(id)`；`stores/library.ts`：`deleteProject(id, cascade=false)` 成功后 `Promise.all([loadAll(), loadTrash(), loadExternalSources()])` 并行刷新。
- `apps/web/src/App.vue`：`askDeleteProject` 收敛为调用 `useProjectDelete(ask)` 的 `confirmDeleteProject`，删除成功后若命中当前激活项目则 `selectGeneral()` 回落；移除不再使用的 `deleteProject` 直接导入。AppSidebar 项目行删除按钮 `title` 由「删除空项目」改「删除项目」。
- 无原生弹窗；ConfirmDialog danger intent、自动聚焦确认钮、Enter/Esc 键盘流全部继承。

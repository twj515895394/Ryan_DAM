## 1. 用户需求

「加一个目录置顶的功能吧 [$design-taste-frontend] [$apple-design] 就是比如有菜单边上有个置顶图标可以点击置顶以及解除置顶」——侧栏目录行悬停操作区（`+` / 铅笔 / `×` 之间）加一枚图钉按钮，点击置顶/取消置顶；置顶目录排在同层最上方，并有常驻徽标标识。

## 2. 设计决策

- **数据**：`folders.pinned BOOLEAN NOT NULL DEFAULT false`（迁移 `0007`，沿用 0006 的 `batch_alter_table` + `sa.false()` 模式）。
- **排序**：`list_folders` 全局 `order_by(pinned.desc(), sort_order, id)`。`build_tree` 按全局行序 append 子节点 → 全局「置顶在前」经保序后**任意层级**的兄弟节点都置顶在前（无需逐层重排）。
- **接口**：`PATCH /folders/{id}` 快速切换语义 `{pinned: true|false}`，走 `update_folder_info`（`pinned is not None` 哨兵，同 `locked` 模式）；改名/锁定等其它 PATCH 不重置 pinned（有测试覆盖）。
- **UI（apple-design / anti-slop）**：图钉按钮与既有铅笔/删除同排同规格（`h-4 w-4` 图标、`rounded` hover 底、`active:scale-95`）；置顶态按钮 `text-accent`（系统强调蓝，与琥珀锁定语义区分）；名称右侧常驻小号图钉徽标（镜像锁徽标模式，`h-3 w-3 text-accent`，title 说明排序语义）。点击 `@click.stop` 不触发目录选中；`updateFolder` 成功即 `loadAll` 重取树，立即重排。

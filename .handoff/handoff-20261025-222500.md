## 1. 本票需求（用户原话摘要）

「如果要设计一下项目的 logo 用于桌面端上，需要哪些地方进行替换，要准备哪些格式的 logo 图片」→ 排查确认后用户：「你可以先改好。图标就以 RD 这样来设计，比如 zcode 的图标也很简单」（附 ZCode 深色字母 tile 参考图）。

## 2. 设计

深色垂直渐变（#3A3A42→#18181E）圆角方块 tile（圆角比例 0.219，类 Apple squircle）+ 白色 Arial Bold Italic「RD」居中——对仗 ZCode 参考图的简洁字母标；小尺寸（16px）目检可辨。

## 3. 交付

**生成脚本（新）`scripts/generate-icons.py`**（Pillow，仅用 .venv）：一次渲染母版并导出全套，改设计只需调常量重跑。

**产物（全部入库）**：
| 文件 | 内容 | 用途 |
|---|---|---|
| `brand/logo-1024.png` | 母版 | 未来衍生/文档 |
| `build/icon.ico` | 16/24/32/48/64/128/256 多尺寸 | electron-builder：exe 文件图标、开始菜单、快捷方式、卸载器 |
| `apps/desktop/assets/icon.png` | 512 | BrowserWindow 窗口/任务栏图标（dev 即生效） |
| `apps/desktop/assets/drag-icon.png` | 64 | 原生 `startDrag` 跟随光标图标（替换旧占位文档 SVG） |
| `public/favicon.ico` + `favicon-32.png` | 16+32 | 5173 浏览器标签页 |

**接线（4 文件）**：
- `package.json`：`build.win.icon = "build/icon.ico"`。
- `apps/desktop/main.cjs`：①`app.setAppUserModelId("com.ryandam.desktop")`（与 build.appId 一致——Windows 任务栏按钮按 AUMID 归属快捷方式图标，缺省显示 Electron 宿主图标）；②`BrowserWindow` 加 `icon: assets/icon.png`；③拖拽图标改 `nativeImage.createFromPath(drag-icon.png)`。资源在 `apps/desktop/assets/` 内，随 `files: apps/desktop/**/*` 进 asar。
- `index.html`：favicon 两条 `<link rel="icon">`；Vite `base:"./"` 下构建产物已确认重写为 `./favicon.*` 且 public 文件复制进 dist（dev 绝对路径可用、打包 file:// 不破）。
- `apps/web/src/components/AppSidebar.vue`：头部品牌位从蓝底 grid 图标 tile 换为 32px 内联 SVG「RD」标识（渐变+斜体，与位图同源设计；`role="img"` + aria-label）。

## 5. 经验 / 坑

- **Windows 图标缓存**：覆盖安装同名 exe 后资源管理器可能仍显示旧图标，是缓存非打包失败（`ie4uinitcache -refresh` 或换输出目录名验证）。
- 任务栏图标归属要 `setAppUserModelId` 与 electron-builder `appId` 一致；开发模式则直接吃 `BrowserWindow.icon`。
- Vite `base:"./"` 会把 index.html 里的绝对 `/favicon.ico` 重写为相对路径并复制 public——dev/打包双场景无需手工相对化处理。
- ICO 由 Pillow 从 1024 母版一次生成多档（`sizes=[...]`），无需 ImageMagick。

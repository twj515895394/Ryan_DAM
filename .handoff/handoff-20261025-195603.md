# Handoff v14 — 预览窗口同目录上下切换增强（跨分页遍历 + 位置指示 + ↑/↓）

## 1. 需求

用户原话：「另外这个预览图片和视频的窗口，加一个同目录下可以进行上下图片切换预览的功能吧」+ 沉浸预览截图（Picture-05.png，头部已有 ← 上一项 / 下一项 → 按钮）。

诊断：同目录上下切换**早已实现**（头部按钮 + ←/→ 键 → `stepPreview` 在已加载列表内循环），但存在三个真实缺口：
1. 只在**已加载的 50 项**内循环（分页边界处到「下一项」会原地回绕，整个目录遍历不到）；
2. 无位置指示，功能不可见、进度不可知；
3. 只绑 ←/→，未响应用户说的「上下」。

## 2. 交付

### App.vue
- `stepPreview` 重写为 **async 分页感知**（提交 `0269505`）：
  - 已加载范围内直接移动；
  - **到达末尾且 `items.length < total`** → `await refreshCurrentAssets(true, page + 1)` 追加下一页再前进（`Math.min` 钳制防追加失败越界）；
  - 真正到末尾/头部才环形回绕；
  - `steppingPreview` 布尔锁防连按并发翻页。
- 新增 computed：`previewPosition`（1 基序号）/ `previewTotal`（`assets.total` 全量数）/ `trashPreviewPosition`（按 id 在 `library.trash` 定位）/ `trashPreviewTotal`；分别传入两处 `<AssetPreview>`。

### AssetPreview.vue
- 新 props `position?: number | null` / `total?: number | null`。
- 头部「← 上一项」与「下一项 →」之间新增 `n / total` 指示（`text-xs tabular-nums text-white/60`，截图 `.handoff/preview-nav-indicator.png`：`1 / 55`）。
- `(total ?? 0) > 1` 才渲染整组按钮 + 指示——单资产目录不再显示无意义切换（Apple HIG 可见性）。
- `onKeydown`：`ArrowUp` 并入 prev、`ArrowDown` 并入 next（预览内切换优先于媒体容器滚动，滚轮仍可用）。
- 顺手修正 v13 后过时注释（代码扩展名现注册为 other，见迁移 0008）。

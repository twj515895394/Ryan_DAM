## 1. 本票需求（用户原话摘要）

「对于这种菜单下有自己目录的，加一个交互功能，通过双击菜单方式展开下一级（或收起折叠），不是一次性全展开，而是要一层一层双击操作才行。而最前面的那个展开箭头，点击之后保持现在全部展开的形式。」

即侧栏目录树两种折叠语义并存：
- **双击目录行**：收起 = 隐藏整个子树；展开 = **只展开直接子级**（更深层保持折叠，逐层点开）。
- **单击箭头（chevron）**：收起 = 隐藏子树；展开 = **恢复整棵子树全部层级**（含此前被双击逐层折叠隐藏的深度节点）。
- 叶子目录双击无副作用；箭头/悬停按钮组 `@dblclick.stop` 防误触双切换。

## 3. 关键坑（本票最重要教训，已写入记忆）

**`<script setup>` 顶层 `const` 编译后位于 `setup()` 内（每实例重新执行），Symbol 类型的 provide/inject key 每实例新建一个 → 父子实例 Symbol 永不相等 → `inject(key, null)` 静默返回 null 不告警，嵌套实例全部回退本地状态，跨层写入看似无效。**
- 诊断路径：行为异常 → vnode `__vueParentComponent.setupState.collapsed` 对比两层集合内容（root=[2,3]、nested=[]）→ 组件内临时 `window.__ftLog` 打点 `gotInject:false` → `fetch('/apps/web/src/components/FolderTree.vue?t=…')` 抓 Vite 编译产物实锤 `const COLLAPSE_STATE_KEY = Symbol(...)` 在 `setup()` 体内。
- **修复：provide/inject key 改用字符串常量**（按值比较，跨实例稳定）。任何「模块级常量」语义（Symbol key、单例缓存）都必须放进普通 `<script>` 块，不能放 `<script setup>`。
- Vite dev 模块抓取必须用页面真实 URL 前缀 `/apps/web/src/...`（带 `?t=`），`/src/...` 返回 SPA 回退 HTML（同既往记忆）。
- IAB `browser.tabs.list()` 返回空数组不可靠，取句柄一律 `tabs.new()` 后 `goto`（同桥 localStorage 按 origin 持久）。

## 1. 项目删除 409 诊断报告（diagnosing-bugs 流程）

### 1.1 结论（先说答案）

**不是代码缺陷。** 用户桌面上 Electron 派生的后端 Python 进程启动于 12:16:53，而项目级联删除后端代码 13:28:17 才提交（`cd9123e`）——正在运行的后端是**升级前的旧版本**。前端发出 `DELETE /projects/{id}?cascade=true` 时，旧 FastAPI 路由**静默忽略未知查询参数**，走旧的非空拦截路径抛 409 `project_not_empty`，于是出现「弹窗承诺级联删除、点击后却 409」的现象。

**处置：用户完全退出并重启 Ryan_DAM 桌面应用后，项目级联删除即可正常工作。**（Python 子进程无热重载；Electron 在应用启动时 spawn 后端。）

### 1.2 证据链

- **时间线取证**：`Get-CimInstance Win32_Process` 读出用户 Electron 与后端 python 子进程的 CreationDate=12:16:53，对比 `git log` 级联提交时间 13:28:17 → 陈旧进程假设成立。
- **RED/GREEN diff loop**（确定性复现，`diag_cascade_repro.py`）：`git worktree` 检出旧提交 `d3269d7` 起隔离后端 → 种子项目 + 无 cascade DELETE → **409，错误文案与用户截图逐字一致**；同一脚本对 HEAD 后端 → **204，级联成功**。同一操作、旧版必红、新版必绿。
- **为何不能用 /health 指纹判版本**：`backend/app/main.py` 的 token 中间件守卫所有路由（含 `/health`），未认证探测一律 401，无法静默读版本号——因此改为前端「遇 404 如实提示重启」的加固方向（见 §2.1）。

## 2. 交付明细

### 2.1 前端加固：陈旧后端如实提示（`fix(web)`）

- `apps/web/src/api/client.ts`：`ApiRequestError` 新增 `readonly status: number`（构造参数第三参，`request()` 抛错时传入 `response.status`），调用方可按 HTTP 状态分类降级。

### 2.2 Markdown 预览支持 GFM 表格（`feat(web)`）

- `apps/web/src/utils/markdown.ts`（重写为索引循环，~110 行）：新增 `TABLE_ROW`（`^\s*\|.*\|\s*$`）与 `TABLE_SEP`（分隔行 `:?-{3,}` 序列）两条正则，`splitTableRow` / `cellAlignStyle`（`:---` 居中、`---:` 右对齐）与 `buildHtmlTable(lines, start)` 解析器；表格分支置于标题分支之前（表头行 + 下一行分隔行才成立）。输出 `<div class="my-2 overflow-x-auto rounded-xl">` 包裹的 `border-collapse text-sm` 表格，单元格 `border border-line px-3 py-1.5`、表头行 `bg-canvas`——宽表可横向滚动，风格对齐 Apple HIG 卡片。

- `apps/web/src/components/ImportJobPanel.vue`：`AUTO_DISMISS_MS = 5000`；`watch(done)`——任务进入完成态（非 queued/running）后启动 `setTimeout(dismissImportJob, 5000)`；重试失败项 / 强制导入等使任务回到运行态时撤销计时；`onBeforeUnmount` 清理计时器。用户手动关闭不受影响。

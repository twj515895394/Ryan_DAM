## 0. 任务来源（用户原话 + 两张截图）

> 「目前目录菜单可以按图1这里进行弹出图2的重命名窗口，我希望这个窗口当做是编辑菜单目录（子目录）的窗口，可以进行菜单的信息编辑。……先加一个锁定的开关功能，一旦锁定的话，该目录就不能删除了，但是该目录下的子目录和文件还是可以单独操作删除的……这个目录信息编辑，信息还可以加哪些信息。」

即：侧栏铅笔入口从「重命名文件夹」NameDialog 升级为「编辑文件夹」弹窗；第一个信息字段 = 锁定开关（锁本目录免删，子目录/资产不受约束）。

## 1. 设计共识（grill-me 三问定案）

1. **级联删除遇锁定 = 整次拦截（409）**：目录级联与项目级联的删除子树中任何一层存在锁定目录，整次删除拒绝，错误信息点名锁定目录；不做「跳过锁定目录继续删其余」的部分删除。
2. **锁只拦删除**：锁定目录仍可重命名、移动；锁定不向下继承（子目录可单独删除、可移出去）。
3. **本弹窗字段 = 名称 + 锁定开关 + 描述（≤2000 字符）**；封面图/颜色标签/归档等留待后续迭代。
4. 默认呈现（已实现并被截图确认）：锁定目录名旁琥珀小锁徽标；锁定行 × 删除按钮禁用 + tooltip「已锁定，需在『编辑文件夹』中解除锁定后才能删除」；单「保存」按钮一次组合 PATCH；项目/标签铅笔入口不变。

## 2. 交付明细

### 2.1 后端（`f611783 feat(backend): folder lock and description with delete guards`）

- **迁移 `0006`**（`backend/alembic/versions/0006_folder_lock_description.py`）：batch_alter_table 为 `folders` 增列 `locked BOOLEAN NOT NULL DEFAULT false`、`description VARCHAR(2000) NULL`；模型 `Folder` 同步（`server_default="0"`）。
- **schema**：`FolderUpdate` 增 `locked: bool | None`、`description: str | None (max_length=2000)`；`FolderOut`/`FolderNode` 输出两列。
- **服务 `folder_service.py`**：
  - `update_folder_info(db, folder_id, *, locked=None, description=FOLDER_INFO_UNSET)`——`locked=None` 表示不改动；`description` 用哨兵 `FOLDER_INFO_UNSET` 区分「键未提供（保持）」与「显式 null/空白（清空）」；`_clean_description` strip 后空串归 None、超 2000 → 422 `validation_error`。
  - `delete_folder` 顶部守卫：自身锁定 → 409 `folder_locked`。
  - `cascade_delete_folder_ids`：子树 id 收集后单条 `IN` 查询扫 `locked.is_(True)`，命中即 409 `folder_locked` 点名该目录（目录级联与项目级联共用此算法，两端点同时受保护）。
- **API**：`PATCH /folders/{id}` 在 name/parent_id 分支后追加 `if "locked" in changes or "description" in changes: update_folder_info(...)`；`description` 键存在才传值（否则传哨兵）。
- **测试**：`test_folders_api.py` +6（锁定拦直删与级联、不继承且允许改名/移动、深层锁定拦祖先级联且点名+解锁后成功、项目级联被锁拦截、描述 strip/保持/清空/超长 422、组合 PATCH）；`test_migrations.py` head 断言 `0005→0006` + 断言两列存在。**131 passed（+6）**。

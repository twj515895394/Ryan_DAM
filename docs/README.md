# Ryan_DAM 文档索引

以产品 Spec 作为需求事实基线，架构、UI 和实施计划作为实现指导。遇到冲突时，以已确认的产品决策为准；实现建议不得反向覆盖产品需求。

## 核心文档

1. [产品规格说明书](./Ryan_DAM_Product_Spec_v1.md) — V1 产品范围与决策记录。
2. [技术架构设计](./TECHNICAL_ARCHITECTURE_V1.md) — Electron、Vue、FastAPI、SQLite、文件存储与后台任务。
3. [UI/UX 设计规范](./UI_UX_DESIGN_V1.md) — 主界面、卡片、预览、提示词、导入任务面板与交互规则。
4. [开发实施计划](./IMPLEMENTATION_PLAN_V1.md) — 分阶段实施、验收点与优先级。

## 文档维护规则

- 产品决策只在产品 Spec 中作为“已确认决策”记录。
- 技术架构与 UI 文档可以提出实现建议，但不能把未确认建议写成用户已作出的产品决定。
- 新增或变更产品决策后，同步更新 Spec 和受影响的设计文档。
- 实现发现风险时优先通过 PoC、测试和工程方案解决；只有影响产品范围或数据安全时才重新向用户确认。

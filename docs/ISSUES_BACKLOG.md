## 票 2 单文件托管导入（选择 IPC + 导入任务 + 落库）【AFK】
**被阻塞于：** 无 - 可以立即开始

### 要构建什么
端到端导入一个文件：Electron 增加受控 IPC `dialog:select-files`（系统对话框，只把用户选中的路径交给后端，不接受 Renderer 任意路径）；前端「导入」按钮激活并可选目标目录（当前选中目录）。后端 `POST /api/v1/imports` 创建 `import_jobs` + `import_job_items`，进程内有限并发 worker 执行技术架构 §4.3 顺序：目标盘空间预检 → staging 复制（`assets/.staging/<job-id>/`）→ SHA-256 分块计算 → 校验 → 原子移动到 `objects/<asset-id>/<filename>` → 事务写入 `assets` 记录（`file_path` 为真实路径）→ 失败补偿清理半文件。前端提供最小任务状态显示（轮询 `GET /api/v1/imports/{id}`：进度、成功/跳过/失败计数），导入期间 UI 不冻结。单文件失败（如目标盘不足）在任务面板显示原因。

### 验收标准
- [ ] 通过 UI 导入一个图片文件后，`assets` 表出现一条 `source_type=managed` 记录，`file_path` 指向托管目录内真实存在的文件
- [ ] 托管目录出现 `objects/<asset-id>/<filename>` 结构；失败/中断时不残留 staging 半文件
- [ ] 导入过程中主界面可继续操作（不冻结）
- [ ] 任务面板显示总体进度与成功/跳过/失败数量
- [ ] 目标盘空间不足时导入被拒绝并给出明确提示，不开始复制
- [ ] 后端测试覆盖：成功导入、失败清理、空间预检、导入 API 鉴权

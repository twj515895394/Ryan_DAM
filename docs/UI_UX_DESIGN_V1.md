# Ryan_DAM UI/UX 设计规范（V1）

- **版本**：v0.1
- **状态**：基于产品 Spec 的 UI 设计建议
- **产品基线**：[Ryan_DAM_Product_Spec_v1.md](./Ryan_DAM_Product_Spec_v1.md)

## 1. 设计目标

Ryan_DAM 是个人创作者的资产库，不是传统企业后台。UI 应突出图片、视频和音频内容，让用户在大量素材中快速浏览、定位、预览、复制提示词，并把真实文件拖到其他应用。

原则：
1. **内容优先**：缩略图是视觉主体，控件不抢占素材空间。
2. **Apple 风格**：浅色、克制、细腻留白、柔和灰阶、清楚的字体层级和少量强调色。
3. **高信息密度但不拥挤**：卡片显示文件名、必要的类型信息和少量标签；详细属性进入预览层。
4. **操作可发现**：常用操作在悬停、选中或预览时出现。
5. **状态清楚**：外部链接、正在处理、失败、重复跳过和回收站状态一目了然。
6. **交互反馈即时**：点击后立刻给出加载/成功/失败反馈，耗时操作转入后台任务。
7. **第一版保持简单**：不设计 AI 标签入口、复杂快捷访问管理或高级工作流。

## 2. 视觉语言

### 2.1 色彩建议

| Token | 建议值 | 用途 |
|---|---|---|
| `--app-bg` | `#F5F5F7` | 应用整体浅灰背景 |
| `--surface` | `#FFFFFF` | 侧栏、卡片、弹窗 |
| `--text-primary` | `#1D1D1F` | 主文本 |
| `--text-secondary` | `#6E6E73` | 次要文本、文件信息 |
| `--border` | `#E5E5EA` | 分割线、卡片边界 |
| `--accent` | `#2563EB` | 主要操作与选中态 |
| `--success` | `#15803D` | 成功状态 |
| `--warning` | `#B45309` | 警告、外部文件失效提示 |
| `--danger` | `#DC2626` | 永久删除等危险操作 |

色值是实现起点，可在前端落地时微调；不要用大量彩色面板区分普通功能。危险操作只在确有风险时使用红色。

### 2.2 排版、间距和圆角

- 使用系统 UI 字体栈，优先清晰的 Windows 中文字体回退。
- 主标题、目录标题、卡片文件名、次要属性建立稳定的字号层级。
- 基础间距以 4/8 px 节奏组织。
- 卡片和弹窗采用克制的圆角；阴影轻微，仅用于浮层。
- 动画短而克制，常规过渡约 120–180ms；不为装饰牺牲响应速度。
- 图标使用统一线性风格，建议 Lucide 图标体系。
- 不使用深色后台模板、大面积渐变或夸张卡片阴影。

## 3. 应用主框架

### 3.1 桌面布局

默认窗口约 1440 × 900。优先使用 Windows 原生标题栏，内容区域采用自定义浅色界面，避免第一版花费时间制作复杂无边框窗口。

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Windows 标题栏：Ryan_DAM                                      □  ×       │
├──────────────────┬───────────────────────────────────────────────────────┤
│ 左侧导航          │ 顶部工具栏                                            │
│                  │ [搜索全部资产……                  ] [视图] [导入]      │
│ 通用资产库        ├───────────────────────────────────────────────────────┤
│   文件夹树        │ 面包屑 / 当前目录名称 / 资产数量 / 筛选与排序          │
│ 项目资产库        ├───────────────────────────────────────────────────────┤
│   项目列表        │                                                       │
│ 标签管理          │              中央资产画廊                              │
│ 回收站            │       [卡片] [卡片] [卡片] [卡片]                     │
│ 设置              │       [卡片] [卡片] [卡片] [卡片]                     │
└──────────────────┴───────────────────────────────────────────────────────┘
```

### 3.2 左侧导航

- 展示通用资产库和项目资产库两个独立入口。
- 通用资产库展开为用户创建的文件夹树。
- 项目资产库展开为项目列表，每个项目拥有自己的子文件夹树。
- 标签管理、回收站、设置放在导航的下部或独立区域。
- 外部资产不创建独立顶层导航；在原有目标文件夹内与托管资产一起显示，使用「外部链接」标识区分。
- 支持折叠侧栏；折叠后保留可识别图标与 tooltip。
- 目录操作放入上下文菜单，避免每行出现过多按钮。
- 删除非空目录时采用保护策略，不允许意外级联删除其中资产。

### 3.3 顶部工具栏

包含全库搜索、网格/列表切换、导入按钮、导入任务状态入口、当前目录上下文与筛选入口。

搜索支持文件名、标签、文件夹名和路径；结果提供文件类型、大小、修改时间等筛选。默认搜索覆盖资产库，允许通过当前目录筛选缩小范围。

## 4. 资产画廊与卡片

### 4.1 网格

- 默认网格，可切换列表。
- 桌面端根据可用宽度自动调整列数；1440 px 窗口下建议约 4–6 列，具体取决于侧栏和缩略图宽度。
- 卡片缩略图区域保持统一视觉框，但媒体内容尽量使用 `object-fit: contain`，避免裁掉竖版 AI 图片、人物或视频关键内容。
- 缩略图区域使用浅灰底，图片比例不一致时自然留白，不拉伸图片。
- 列表模式显示文件类型图标、文件名、来源、大小、修改时间和标签等核心字段。

### 4.2 卡片信息

每张卡片显示：
1. 图片缩略图、视频代表帧、音频封面/音频卡片或文档格式图标。
2. 文件名，过长时单行省略，完整名称通过 tooltip 或详情查看。
3. 与类型有关的信息：图片尺寸/大小、视频时长、音频时长、文档格式与大小。
4. 少量标签，更多标签在预览信息面板查看。
5. 外部资产显示低干扰的「外部链接」标识。
6. 视频卡片在缩略图角落显示时长。

### 4.3 悬停与选中

悬停时显示精简操作：
- 选择框/多选入口。
- 更多操作菜单。
- 图片/视频提示词操作：没有提示词时显示「添加提示词」；有提示词时显示「查看提示词」。
- 外部资产显示「转为系统托管」；不提供重命名、修改源文件或删除原文件操作。

选中状态使用细边框或轻微背景强调，不使用强烈整卡色块。多选模式下清楚显示已选数量和批量操作入口。

### 4.4 文件拖出

- 从卡片主要媒体区域开始拖动时，支持拖出真实原始文件。
- 拖动与单击预览、多选点击应区分；选择框、菜单按钮不触发文件拖出。
- 系统托管资产拖出托管文件；外部资产拖出原始路径文件。
- 拖出不改变源文件、不移动资产。
- 必须在 Windows Electron 中验证拖入 Chrome 上传区域的结果，不能只验证应用内拖动。

## 5. 沉浸式预览

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ [关闭]  文件名                                     [上一项] [下一项] […] │
├───────────────────────────────────────────────┬──────────────────────────┤
│                                               │ 信息面板                 │
│           媒体预览主区域                      │ 文件名 / 类型 / 来源     │
│                                               │ 大小 / 修改时间 / 路径   │
│ 图片：缩放、适应窗口、原始尺寸                 │ 标签                     │
│ 视频/音频：播放、暂停、进度、音量               │ 提示词（仅图片/视频）    │
│ 文档：对应的内置预览组件                       │ [查看/添加提示词]        │
│                                               │ [移动] [重命名] […]     │
└───────────────────────────────────────────────┴──────────────────────────┘
```

- 预览采用沉浸式浮层/全屏工作区，侧边信息面板不长期占据主画廊。
- 关闭后恢复之前的目录、滚动位置、筛选和选中状态。
- 支持上一项/下一项浏览；Esc 关闭预览可作为默认交互。
- 图片预览提供适应窗口和原始尺寸/缩放能力，不要求复杂编辑工具。
- 视频/音频显示播放控制、进度、音量和时长；格式无法播放时提供「在系统默认应用中打开」回退。
- PDF、TXT、Markdown、JSON、CSV 使用相应预览；Office 文件显示基础属性与下载/外部打开入口。
- 信息面板内可以编辑标签、查看来源状态和执行常用管理操作。

## 6. 提示词查看与编辑

提示词仅用于图片与视频资产。

- 没有提示词时，卡片悬停区和预览信息面板显示「添加提示词」，不显示「查看提示词」。
- 已有提示词时显示「查看提示词」。点击打开弹窗，提供完整文本、「复制提示词」按钮和「编辑」入口。
- 编辑状态下提供多行文本框、保存和取消。
- 单字段保存完整提示词，不拆分正向/负向字段。
- 保留换行、空格和特殊字符，不自动改写、不格式化。
- 复制按钮复制完整原文。
- 保存失败时保留编辑内容并显示原因。
- 不显示 AI 反推提示词入口。

## 7. 导入与外部目录

### 7.1 导入入口

点击「导入」后提供基础选项：
- 导入文件（多选）。
- 导入文件夹（保留子目录结构）。
- 关联外部目录（用户指定资产库目标文件夹）。

托管导入会复制文件；外部目录关联只建立索引，不复制源文件。

### 7.2 导入任务面板

使用右侧抽屉或浮层，不打断当前浏览位置。

```text
导入任务
正在导入：AI素材/角色/角色A.png
[██████████░░░░░░] 63%

总计 240 项
成功 142   跳过 12   失败 3   处理中 83

[查看失败原因] [重试失败项目]
```

- 显示总体进度、当前阶段、成功/跳过/失败数量。
- 阶段示例：扫描、哈希检查、复制文件、生成缩略图。
- 缩略图失败不等于文件导入失败，应分别显示。
- 空间不足时，导入前提示更换位置或取消；导入过程中失败文件安全清理，已成功文件保留。
- 任务完成后允许查看失败原因和重试失败项。
- 不实现复杂的暂停/恢复调度中心。

### 7.3 外部目录关联

- 通过导入/关联流程选择源目录和资产库目标文件夹。
- 外部素材进入用户指定的逻辑目录，源子目录层级在资产库中保留。
- 外部资产与托管资产使用同一套卡片和预览。
- 外部来源标识清晰但低干扰。
- 手动重新扫描入口放在关联目录的上下文菜单或详情操作中。
- 解除关联前显示将移除的外部资产数量；确认后移除仍为 external 的索引，不删除原始文件；已转托管资产保留。
- 转托管成功后原卡片就地更新为系统托管状态，不新增重复卡片。

## 8. 标签、批量操作与回收站

- 标签管理提供全局标签列表、创建、重命名与删除。
- 资产卡片只显示少量标签，避免多行标签撑高卡片。
- 详情面板提供完整标签编辑入口。
- 批量选中后提供批量添加标签、移除标签、移动和删除。
- 仅显示当前所选资产均可执行的操作；外部资产不能触发修改源文件的操作。
- 批量删除前显示数量并确认；执行后反馈成功与失败数。
- 回收站显示文件名、类型、删除时间和原逻辑文件夹，支持恢复、永久删除和清空。
- 永久删除/清空使用明确警告；外部资产移除不进入回收站，因为不删除原文件。

## 9. 空状态、加载和错误反馈

所有主要页面都要覆盖：
- **首次使用**：简短说明与「导入文件」「导入文件夹」「关联外部目录」操作。
- **空文件夹**：显示目录名称和导入入口，不显示大面积装饰插画。
- **加载中**：轻量 skeleton，避免闪烁与整页白屏。
- **无搜索结果**：显示关键词和清除筛选操作。
- **外部路径失效**：显示外部链接失效标识、原路径与重新扫描/重新关联入口。
- **缩略图生成失败**：回退类型图标并提供轻量说明。
- **导入失败**：显示失败文件、可理解原因和重试入口。
- **磁盘空间不足**：显示目标盘与可用空间信息，提供更换位置/取消。
- **回收站为空**：简单提示，无需复杂插画。

## 10. 响应式布局

- **桌面宽屏**：固定/可折叠左侧导航，中央多列网格，完整顶部工具栏。
- **中等宽度**：侧栏可折叠，减少卡片列数，筛选入口收纳到菜单。
- **手机**：导航改为抽屉/独立导航页；优先基础浏览、搜索和预览；复杂批量操作不作为重点。
- 缩略图列数根据内容区宽度变化，而不是只按设备型号切换。
- 预览侧边面板在窄屏下改为底部信息抽屉或单独详情页。

## 11. 关键交互验收

1. 卡片默认状态简洁，悬停操作不遮挡主体。
2. 竖版图片和视频代表帧不会被强制裁掉关键内容。
3. 点击卡片打开预览，关闭后恢复原浏览位置。
4. 无提示词只出现「添加提示词」；有提示词出现「查看提示词」。
5. 提示词弹窗能完整复制原文，并能编辑保存。
6. 外部资产与托管资产卡片布局一致，仅来源标识和可用操作不同。
7. 导入任务运行时仍可浏览其他已完成资产。
8. 批量选择、卡片点击和原生文件拖出不互相误触。
9. 解除外部目录关联不会删除原文件；转托管不会产生重复资产卡片。
10. 界面在空数据、错误、加载和超长文件名状态下仍然可用。

## 12. V1 不设计的 UI

- AI 自动标签、AI 反推提示词入口。
- 复杂的自定义工作台/仪表盘。
- 高级搜索构建器、智能集合和规则引擎。
- 视频多帧选择、动态缩略图与音频波形编辑。
- 任务暂停/恢复/并发调度中心。
- 多用户、权限管理和云端同步。
